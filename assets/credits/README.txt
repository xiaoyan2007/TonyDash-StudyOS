鸣谢名单校徽目录
================

设置页「鸣谢名单」会按学校缩写自动查找本目录下的图片：

    UM.png    澳门大学
    UNNC.png  宁波诺丁汉大学
    ZUFE.png  浙江财经大学
    ZJGSU.png 浙江工商大学
    YNU.png   云南大学

当前状态
--------
本目录已放入 5 所学校的校徽（由用户从「大学logo/」提供，已做如下处理）：

* UM / ZUFE / ZJGSU / YNU：圆形校徽，已去掉圆以外的白色背景，输出为
  256 × 256 透明 PNG，卡片里直接按原样显示。
* UNNC（宁波诺丁汉）：竖向徽标，按原图保留形状，仅裁到内容包围盒
  （166 × 228），不做圆形化处理。

显示规则
--------
* 找到图片时：直接原样显示（等比缩放到 48 × 48 高度内，居中）。
* 图片缺失时：自动改用程序绘制的圆角渐变徽标（缩写 + 学校主题色），
  保证界面不会出现空白。

如何替换
--------
1. 把官方校徽 PNG 重命名为上面的缩写（如 ZJGSU.png）。
2. 放回本目录。
3. 重新运行 / 重新打包即可，无需改代码。

圆形校徽建议预先去掉白底（可用任意图片工具「去白底 / 建立圆形蒙版」），
这样卡片里的观感最好；竖向徽标请保持原图形状，不要强行圆形化。

注意：请确认校徽的使用符合该校的标识规范与版权要求。
