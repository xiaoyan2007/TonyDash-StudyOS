TonyDash学习终端 Beta 1.3
发布日期：2026-11-03
上手引导 · 深色模式 · 作息改版
不用猜，界面自己会告诉你怎么用；夜里也照样清楚。

【新增】
- 三步上手引导：首次启动自动高亮「添加第一门课程 → 待办输入框 → 新增考试」，配说明气泡，可上一步/跳过，完成后不再打扰
- 上手清单：主页新增三项微任务（建课 / 加待办 / 记考试），做完自动打勾，全部完成或手动关闭后收起
- 页面使用提示：课表、待办、考试页头新增常驻蓝色提示行，说明该页关键操作
- 重看引导：设置页新增「重新查看上手引导」，随时可以再看一遍
- 深色模式：标题栏一键切换，设置页也有浅色 / 深色分段控件，深色下文字、卡片、输入框、滚动条、日历与弹窗全部重绘
- 主题令牌化：浅色与深色两套配色、背景渐变、玻璃卡片阴影与高光全部随模式变化，切换后没有残留的浅色观感
- 作息时间下拉框：每一节的起止时间改为小时 / 分钟两个下拉框，点击即可直接输入编辑
- 滑块缓动：外观毛玻璃强度改为平滑滑块，拖动时数值连续过渡
- 时钟秒数：主页大时钟的秒与时分同字号，用冒号连成 HH:MM:SS

【变更】
- 文字放大：标题栏品牌名与副标题、主页各处小字、卡片脚注、周概览日期按美学重新分级
- 主行动按钮：主页按数据状态切换为「添加第一门课程」或「打开课程表」
- 按钮文案：「去勾待办 / 考试安排」改为「查看今日待办 / 查看考试安排」
- 页面副标题：动态状态与操作提示分离，提示不再被数据覆盖
- 数据格式：升级到 v3，新增 onboarded / checklist_dismissed / hints_dismissed / theme_mode，旧数据自动补默认值

【修复】
- 与背景同色按钮获得焦点时四个圆角出现蓝色弧线（焦点环画在控件外侧被裁掉）
- 主页新增上手清单后，1280×820 下摘要卡与本周概览被挤重叠
- 作息时间用滚轮调整容易误改，改为下拉框并屏蔽滚轮
- 窗口反复创建时全局样式表被重复应用，导致界面重建越来越慢
